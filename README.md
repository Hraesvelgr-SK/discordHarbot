# discordHarbot
1. doh
	사용법: !doh
	주사위를 굴려 1에서 100 사이의 랜덤 숫자를 생성하고 결과를 보여줍니다.
2. d20
	사용법: !d20
	1에서 20 사이의 랜덤 숫자를 굴리고, 유저의 평균 스탯에 따라 결과를 조정하여 1에서 20 사이의 값을 반환합니다.
3. evade
	사용법: !evade
	50개의 100면 주사위를 굴린 후, 25 이하의 숫자가 나온 횟수와 25 초과의 숫자가 나온 횟수를 계산하여 결과를 보여줍니다.
4. dr
	사용법: !dr (다이스 개수)d(다이스 눈 수) (예시: !dr 1d5)
	지정한 개수의 주사위를 굴려 결과를 보여줍니다.
5. ctd
	사용법: !ctd (목표값) (예시: !ctd 50)
	1d100 주사위를 굴리고, 결과에 따라 성공/실패를 판단하여 메시지를 반환합니다.
6. ccm
	사용법: !ccm (굴릴 파라미터)/(굴릴 파라미터)/... (예시: !ccm 근력/체력/운)
	각 파라미터에 대해 3d6 주사위를 굴려 캐릭터의 스탯을 생성하여 보여줍니다.
7. ds
	사용법: !ds
	2개의 6면 주사위를 굴리고, 각각의 결과와 합계를 보여줍니다.
8. createCharacter
	사용법: !createCharacter (체력) (근력) (민첩) (지능) (지혜) (행운) (무기 사거리) (무기 데미지)
	캐릭터를 생성하고 해당 정보를 데이터베이스에 저장합니다.
9. charStat
	사용법: !charStat
	현재 사용자의 캐릭터 스탯을 보여줍니다.
10. evadeCharAtk
	사용법: !evadeCharAtk @멘션
	멘션한 캐릭터의 공격을 회피 시도하고 결과를 보여줍니다.
11. charRunAway
	사용법: !charRunAway (거리) @멘션
	멘션한 캐릭터에게서 도망가려 시도하고 성공 여부를 보여줍니다.
12. healChar
	사용법: !healChar (회복량) (예시: !healChar 10)
	캐릭터의 체력을 (회복량)만큼 회복시키고 결과를 보여줍니다. (회복량을 비울경우 최대회복으로 간주합니다)
13. setCharHP
	 사용법: !setCharHP (새 체력)
	캐릭터의 체력을 지정한 값으로 설정합니다.
14. !charAttack 
	캐릭터의 명중판정을 진행합니다.
